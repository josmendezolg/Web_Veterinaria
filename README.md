# 🐾 Web Veterinaria

Una página web diseñada para una clínica veterinaria, enfocada en presentar los servicios de manera clara e interactiva.

## 🚀 Tecnologías utilizadas
* **HTML5:** Estructura semántica de la página.
* **CSS3:** Diseño, estilos y responsividad.
* **JavaScript:** Lógica de interactividad en el frontend.
